# 特征

一个环里「$1$ 反复相加多久会回到 $0$」决定了它包含的最基本的域。这个整数（或 $0$）就是特征，它刻画了环的「算术底色」。

> [!note] 定义（caractéristique）
> $K$ 域。$\varphi: \mathbb{Z} \to K$ 是环同态，$1_\mathbb{Z} \mapsto 1_K$，$n \mapsto \underbrace{1_K + \cdots + 1_K}_{n\ \text{个}}$。设 $I = \ker(\varphi) = m\mathbb{Z}$。
> - 若 $I = 0$，则 $\varphi$ 单，$\mathbb{Z} \subset K$；此时 $\mathcal{F}rac(\mathbb{Z}) = \mathbb{Q}$ 是 $K$ 的子域，定义 $\mathrm{car}(K) = 0$。
> - 若 $I \neq 0$，则 $\mathbb{Z}/I$ 是整环 $\Rightarrow I = p\mathbb{Z}$（$p$ 素），$\mathbb{Z}/p\mathbb{Z} \hookrightarrow K$ 即 $\mathbb{F}_p$，定义 $\mathrm{Car}(K) = p$。

> [!tip] 直觉
> 环同态 $\mathbb{Z} \to K$ 是「$K$ 中整数」的唯一来源。它的核只能是 $0$ 或 $p\mathbb{Z}$，于是每个域要么含 $\mathbb{Q}$（特征 $0$，如 $\mathbb{R}, \mathbb{C}$），要么含 $\mathbb{F}_p$（特征 $p$）。$\mathbb{Q}$ 与 $\mathbb{F}_p$ 是最小的域，称为素域（sous corps premier）。

> [!example] 例子
>
> - 特征 $0$：$\mathbb{Q}$、$\mathbb{Q}_p$、$\mathbb{R}$、$\mathbb{C}$、$\mathbb{Q}\llbracket t \rrbracket$。
> - 特征 $p$：$\mathbb{F}_p$、$\mathbb{F}_{p^n}$、$\mathcal{F}rac(\mathbb{F}_p[x]) = \mathbb{F}_p(x)$。

> [!warning] 陷阱
>
> - 特征只能是 $0$ 或素数；不可能出现「特征 $6$」。
> - 特征 $p$ 的环中 $(x + y)^p = x^p + y^p$，二项式中间项消失，这与特征 $0$ 时不同。
> - 「素域」指的是 $\mathbb{Q}$ 或 $\mathbb{F}_p$，它是该特征下最小的域，而不是指「素理想」。
