# 向量空间与子空间

以下设 $\mathbb{K}$ 为域，$E$ 为 $\mathbb{K}$ 上的向量空间（$\mathbb{K}$-e.v.）。

## 由公理推出的基本性质

> [!note] 命题
> $\forall a\in\mathbb{K},\ x\in E$：
> (1) $0_{\mathbb{K}}\,x = 0_E$ 且 $a\,0_E = 0_E$；
> (2) $a(-x) = -(ax) = (-a)x$。

**Preuve :** $0_{\mathbb{K}}x + 0_{\mathbb{K}}x = (0_{\mathbb{K}}+0_{\mathbb{K}})x = 0_{\mathbb{K}}x \implies 0_{\mathbb{K}}x = 0_E$。
$a0_E + a0_E = a(0_E+0_E) = a0_E \implies a0_E = 0_E$。
$a(-x) + ax = a(-x+x) = a0_E = 0_E \implies a(-x) = -(ax)$。
$(-a)x + ax = (-a+a)x = 0_{\mathbb{K}}x = 0_E \implies (-a)x = -(ax)$。

> [!note] 命题
> $\forall a\in\mathbb{K},\ x\in E$：$ax = 0_E \implies \big(a = 0_{\mathbb{K}} \text{ 或 } x = 0_E\big)$。

**Preuve :** 设 $a\neq 0_{\mathbb{K}}$，即 $a\in\mathbb{K}^{*}$ 可逆。则 $a^{-1}ax = a^{-1}\,0_E = 0_E$，即 $x = 0_E$。

## 乘积空间与函数空间

> [!note] 命题（乘积）
> $E, F$ 是 $\mathbb{K}$-向量空间，在 $E\times F$ 上定义数乘
> $$\mathbb{K}\times(E\times F)\longrightarrow E\times F,\qquad (a,(x,y))\longmapsto (ax, ay),$$
> 则 $E\times F$ 是 $\mathbb{K}$-向量空间。

> [!note] 推论
> $E_1,\dots,E_n$ 是 $\mathbb{K}$-向量空间，则 $E_1\times\cdots\times E_n$ 是 $\mathbb{K}$-向量空间；特别地 $\mathbb{K}^n$ 是 $\mathbb{K}$-向量空间。

> [!note] 命题（函数空间）
> $E$ 是 $\mathbb{K}$-向量空间，$X$ 是集合，记 $\mathcal{F}(X,E) = E^X$。对 $f, g: X\to E$ 定义
> $$(f+g)(x) = f(x)+g(x),\qquad (af)(x) = a\,f(x),$$
> 则 $E^X$ 是 $\mathbb{K}$-向量空间。

## 线性组合与向量子空间

> [!note] 定义（线性组合）
> $(x,y)\in E^2$，$(\lambda,\mu)\in\mathbb{K}^2$。称 $z = \lambda x + \mu y$ 为 $x$ 与 $y$ 的线性组合（une combinaison linéaire）。

> [!note] 定义（向量子空间）
> $F\subset E$ 称为 $E$ 的向量子空间（sous-espace vectoriel），若
> - $0_E\in F$；
> - $\forall\alpha,\beta\in\mathbb{K},\ (x,y)\in F^2$，$\alpha x + \beta y\in F$。

> [!info] 子空间的等价判定
> $F\subset E$ 是子空间 $\iff$
> $F\neq\varnothing$；$\quad\forall(\lambda,y)\in\mathbb{K}\times F,\ \lambda y\in F$；$\quad\forall u,v\in F,\ u+v\in F$。

> [!example] 例
> - 由递推关系给出的序列子集：$a,b$ 给定，
> $$\left\{(u_n)_{n\in\mathbb{N}}\in\mathbb{R}^{\mathbb{N}} \;\middle|\; \forall n\in\mathbb{N},\ u_n = a\,u_{n+1} + b\,u_{n+2}\right\}\subset\mathbb{R}^{\mathbb{N}}$$
> 是 $\mathbb{R}$-向量空间。
> - $\operatorname{Hom}_{\mathbb{K}}(E,F)\subset F^E$（$E\to F$ 的线性映射，application linéaire）是 $\mathbb{K}$-向量空间。
> - $\mathbb{R}[X]\subset\mathcal{C}(X)$、$\mathbb{R}[X]\subset\mathbb{R}^{\mathbb{N}}$ 是 $\mathbb{R}$-向量空间的例子；另有例子说明某空间是 $\mathbb{R}$-向量空间而不是 $\mathbb{C}$-向量空间。

## 由一族向量生成的子空间

> [!note] 命题（子空间的交）
> $E_i\ (i\in I)$ 是 $E$ 的向量子空间，则 $\bigcap_{i\in I} E_i$ 是 $E$ 的向量子空间。

> [!note] 定义（由 $A$ 生成的子空间）
> $A\subset E$。存在包含 $A$ 的最小的 $E$ 的向量子空间，记为 $\operatorname{Vect}(A)$，称为由 $A$ 生成的 $\mathbb{K}$-向量子空间（或记作 $\operatorname{Span}(A)$）。

> [!info] 注记
> $$\operatorname{Vect}(A) = \bigcap_{\substack{A\subset F\subset E\\ F \text{ 是子空间}}} F.$$

> [!note] 定义（一族向量生成的子空间）
> $A = (a_i)_{i\in I}$ 是 $E$ 中一族向量，$\mathcal{A} = \{a_i \mid i\in I\} = \operatorname{Im}(A)$。称 $\operatorname{Vect}(\mathcal{A})$ 为由 $A$ 生成的向量子空间，记为 $\operatorname{Vect}(A)$。

> [!info] 注记
> 若 $\mathcal{A} = \varnothing$，则 $\operatorname{Vect}(\varnothing) = \{0_E\}$。

> [!note] 命题
> 当 $\mathcal{A}$（或 $I$）有限，$\mathcal{A} = (a_i)_{i\in[\![1,n]\!]}$，$n\in\mathbb{N}^{*}$ 时，
> $$\operatorname{Vect}(A) = \left\{\sum_{i=1}^{n}\lambda_i a_i \;\middle|\; \forall i\in[\![1,n]\!],\ \lambda_i\in\mathbb{K}\right\},$$
> 即 $a_1,\dots,a_n$ 的一切线性组合之集。

> [!note] 定义（向量直线）
> 由一个非零向量生成的子空间称为向量直线（une droite vectorielle）。
> $a\in E$，$\operatorname{Vect}(\{a\}) = \operatorname{Vect}(a) = \mathbb{K}a$。
