# 群论学习路径（代数III）

> Marc Rosso 讲义（USTC 2026 秋）的主线地图。课程有**两条彼此独立的主线**，只在少数地方汇合；
> 认错线是这一课最常见的困惑来源，所以下面分开画。

## 0. 两条线，一句话

- **线 A（拆群）**：把群拆成小块，看每块能否再取商 —— 子群 → 陪集 → 正规 → 商 → 同构定理 → 导群/交换化 → 扩张。
- **线 B（显形）**：让群作用在集合上，用轨道与计数把「作用的信息」翻译成「群结构的信息」 —— 群作用 → 轨道-稳定子 → 类方程 → Sylow → 对称群 → 分类。

**汇合点**：$\mathfrak{A}_5$ 单性（线 B 的计数证明单性）、$\mathrm{PSL}_n$ 单性（线 A 的完美性 + 线 B 的传递性）、以及小阶群分类（两条线的判据同时上场）。

## 1. 线 A：拆群

```
[[代数III/概念/群]]  群的定义与例子（循环、置换、线性群）
    ↓ 内部结构
[[子群与陪集]]  子群、陪集、Lagrange（|H| 整除 |G|）
    ↓ 哪种子群能取商
[[正规子群]]  正规的三副面孔（左=右陪集 / 共轭不变 / 核）
    ↓ 商结构
[[商群]]  G/H 的乘法为什么良定义
    ↓ 分解与比较
[[同构定理]]  三个同构定理：核与像控制一切
    ↓ 交换化
[[导群]]  换位子测不可交换 → 最大交换商 G/D(G) → 可解
    ↓ 反向操作：把两块拼回去
[[代数I/概念/半直积]]  分裂扩张；[[代数I/概念/正合列]]  正合、短正合、分裂判据
```

**这条线的读法**：每一步都在回答「上一步造出的东西，怎么再拆一次」。
正规性不是审美要求，而是「陪集之间能相乘」的唯一条件；同构定理则是「任何同态都能被核与像夹住」。

## 2. 线 B：显形

```
[[代数III/概念/群作用]]  作用、轨道、稳定子、忠实/传递
    ↓ 轨道-稳定子
|O(x)| = [G : Stab(x)]  →  类方程（共轭作用）
    ↓ 计数工具
[[Sylow定理]]  存在、共轭、计数（n_p ≡ 1 mod p，n_p | m）
    ↓ 结构定理
[[代数III/概念/对称群]]  生成元、循环分解、共轭类 = 循环型；D(S_n) = A_n
    ↓ 单性
[[A5单性与60阶群]]  元素普查 + 逐类排除；反向：60 阶单群唯一
    ↓ 几何应用
[[SO3的有限子群]]  极点集 + Burnside → 循环 / 二面体 / A4 / S4 / A5
```

**这条线的读法**：作用提供「计数」，计数提供「存在性」，存在性提供「结构」。
Sylow 定理之所以强，是因为它把「整除关系」变成了「子群必然存在」，而元素计数再把「存在太多」变成「矛盾」。

## 3. 汇合：分类与单性

- [[小阶群分类]] — $|G| \leqslant 15$ 共 28 个群。分类的完备性靠「阶型划分穷尽 + 每种情形被迫同构于标准模型」，去重靠 $\operatorname{Aut}$ 的轨道数。
- [[四元数群]] — $Q_8$：$C_4$ 被 $C_2$ 扩张却**不分裂**的那一格，是「非交换 ⇒ 半直积」的反例。
- [[A5单性与60阶群]] — 线 B 的终点之一。
- [[PSLn单性]] — 线 A 的完美性与线 B 的 2-重传递性在这里接头。

## 4. 线性群与约化（讲义后半）

- [[经典群]] — $\mathrm{GL}/\mathrm{SL}/\mathrm{O}/\mathrm{SO}/\mathrm{U}/\mathrm{Sp}$ 的统一视角：保持某种线性数据的自同构群。
- [[线性群与特殊线性群]] — 中心、平延（transvection）、$\mathfrak{D}(\mathrm{SL}_n)=\mathrm{SL}_n$。
- [[PSLn单性]] — 商掉中心才单；两个例外 $(2,\mathbb{F}_2)$、$(2,\mathbb{F}_3)$。
- [[自同构与群的对称性]] — $\operatorname{Aut}(G)$、$\operatorname{Int}(G)$、$\operatorname{Out}(G)$ 的分层；$\operatorname{Aut}(C_n)\cong(\mathbb{Z}/n\mathbb{Z})^\times$ 见 [[代数I/概念/单位群]]。
- [[Frobenius标准型]] — 不假设特征值在域内的相似分类；与 [[代数II/概念/Jordan标准型]] 分工（后者要求分裂）。

## 5. 有限阿贝尔群与特征标（讲义第 6 章）

- [[有限阿贝尔群结构]] — 不变因子链 $d_1\mid\cdots\mid d_r$；指数 = $d_r$；唯一性靠 $p^k$-挠子群的计数。按层计数 $b_k=\#\{i:\lambda_i\ge k\}$ 同时给出初等因子与嵌入判据；可除（内射）群让「短正合列分裂」变成可判定的性质。
- [[特征标与正交关系]] — 对偶群 $\hat A$、延长定理、第一正交关系；本质是有限阿贝尔群上的 Fourier 展开。

## 6. 习题课的另外两条入口

讲义从「群结构」出发，习题课常从「对象与对称性」出发 —— 两条路在 [[自同构与群的对称性]] 汇合。

- [[伽罗瓦群]] — 保持根间全部多项式关系的置换；方程的对称群。
- [[代数III/概念/模]] — 环作用：$\rho:R\to\operatorname{End}(V)$。
- [[域上代数]] — 标量经中心作用：$\rho:K\to Z(R)$。
- [[自由积]] — $\mathrm{PSL}_2(\mathbb{Z})\cong C_2*C_3$：轨道定生成元、基本域顶点循环定关系。
- [[Borel子群与旗簇]] — 旗的稳定子；$\mathrm{GL}_n$ 作用于旗流形。
- [[Bruhat分解]] — 旗流形按相对位置被 Schubert 胞腔剖分。
- [[Weyl群]] — $W=N_G(T)/T$，在 $\mathrm{GL}_n$ 情形 $\cong\mathfrak{S}_n$，是 Bruhat 分解的组合指标。
- [[群论的目的与历史]] — 为什么会有群论、五次的公式为何找不到、抽象化怎么发生。

## 7. 三句话

1. **拆群靠正规性**：只有正规子群能取商，同构定理是这个事实的语法。
2. **作用靠计数**：轨道-稳定子把「有多少」变成「是什么」；Sylow 是这条线的核心工具。
3. **分类靠穷尽 + 去重**：先证情形划分穷尽，再用不变量与 $\operatorname{Aut}$-轨道排除重复；只报清单不报完备性，等于没分类。
