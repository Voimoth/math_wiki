# 表示论简史（Schur–Weyl 这条线）

> [!question] 这条线回答什么
> 为什么 $\mathfrak{S}_n$（换因子）与 $\mathrm{GL}_d$（变换向量）的不可约表示，由同一批分拆 $\lambda\vdash n$ 标号？

## 时间线

| 时间 | 谁 | 做了什么 | 逼出它的困难 |
|---|---|---|---|
| 1890 | Hilbert | 基定理／不变量环有限生成（非构造） | 不变量论「算出显式生成元」的纲领走不通 |
| 1885 / 1896 | Dedekind → Frobenius | 群行列式 $\det(\sum a_g g)$ 该分解成什么（1885 一篇旧文 + 1896 年 4 月 12 日起的通信） | 没有「表示」这个概念可用 |
| 1896-07-16 | Frobenius | 向柏林科学院提交群特征标（*Über Gruppencharaktere*） | 任意有限群需要一套通用的 Fourier 型分解 |
| 1897–1899 | Frobenius | 诱导特征标、特征标张量积、Frobenius 互反（1898 引入诱导表示） | 子群与母群的表示怎么互相搬 |
| 1900 / 1901 | Frobenius | 完全定出 $\mathfrak{S}_n$ 的特征标 / 交错群的特征标 | 共轭类 = 分拆，答案只能用分拆写 |
| 1901 | Schur（博士论文，导师 Frobenius） | 《Über eine Klasse von Matrizen, die sich einer gegebenen Matrix zuordnen lassen》：与给定矩阵交换的矩阵代数；$\mathrm{GL}_n$ 多项式表示完全可约、分拆标号、Schur 函数 | $\mathrm{GL}_n$ 无限，有限群的正交关系不能用；有限维代数却有结构定理 |
| 1927 | Schur | 《Über die rationalen Darstellungen der allgemeinen linearen Gruppe》重证 1901 的结果 | 1901 那篇不好读 |
| 1928 / 1939 | Weyl | 《Gruppentheorie und Quantenmechanik》/《The Classical Groups》 | 把对偶变成量子力学与不变量论的标准工具；「Schur–Weyl」之名由此而来 |
| 1954 / 1955 | Bruhat（经典群）/ Chevalley（一般情形） | $G=\bigsqcup_{w\in W}BwB$ | 半单群降到任意域后，群的骨架变成 Weyl 群的 word；旗簇的 Schubert 胞腔 |
| 1965 | Iwahori–Matsumoto | $B$-双不变函数的卷积代数：由 $T_w$ 生成，$(T_s-q)(T_s+1)=0$ + 辫关系（Publ. Math. IHÉS 25, 5–48） | $\mathbb{F}_q$ 上做表示论／诱导表示的 intertwining 算子 |
| 1985 | Drinfeld / Jimbo | 包络代数的 $q$-形变（Hopf 代数），$q\to1$ 退回 | 可积系统与统计力学的 Yang–Baxter 方程 |
| 1986 | Jimbo | 《A $q$-analogue of $U(\mathfrak{gl}(N+1))$, Hecke algebra, and the Yang–Baxter equation》（Lett. Math. Phys. 11, 247–252） | Hecke 代数与量子群在同一张量空间上互为中心化子 ⇒ 对偶整个 $q$ 化 |
| 1995 / 1998 / 1999 | Crane / Baez–Dolan / Khovanov | 「范畴化」一词（JMP 36, 6180）/ 纲领（Contemp. Math. 230）/ Jones 多项式的范畴化（arXiv math.QA/9908171） | 把等式换成自然同构，把系数换成重数 |

## 三次「同一个对象换语言」

- **群 → 函数**：Frobenius 从群出发得到 $\mathfrak{S}_n$ 的特征标，Schur 从中心化子出发得到 Schur 函数——两者是同一批函数。
- **$\mathbb{C}$ → $\mathbb{F}_q$**：Bruhat 把 $\mathrm{GL}_n$ 压成 $\mathfrak{S}_n$ 的 word，Hecke 代数给 $\mathfrak{S}_n$ 的群代数补上一个参数 $q$，$q$ 数的是旗的个数。
- **经典 → 量子**：Drinfeld–Jimbo 的形变让同一个 $q$ 在 Hecke 代数一侧现身，Schur–Weyl 对偶原样成立（量子 Schur–Weyl 对偶）。

## 需要标注的不可靠处

- **Gordan 的「Das ist nicht Mathematik, das ist Theologie」**：最早的书面出处晚于事件约 25 年、在 Gordan 去世之后；是否说过、是批评还是惊叹都无定论（Wikipedia *Paul Gordan* 条目据 McLarty 的考证）。不要当史实引用。
- **双中心化子的措辞**：$\operatorname{End}_{\mathrm{GL}_n}(V^{\otimes n})$ 与 $\mathfrak{S}_n$ 互为换位子，是 Weyl 一代的表述；Schur 1901 原文是否已这样写，未核原文。
- **$S_\infty$**：$\Lambda(x)=R(x)^{S_\infty}$ 这类写法属于现代对称函数教材的框架（Macdonald 一系），Schur 时代没有；史料里未见 Schur 使用 $S_\infty$ 的痕迹（此条为推断）。
