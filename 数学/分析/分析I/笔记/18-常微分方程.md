# 18 常微分方程

ODE: ordinary differential equation

## 例：最速降线

$$\frac{1}{2}v^2 = gy$$
$$\frac{ds}{dt} = v$$
$$\frac{ds}{dx} = \sqrt{1+(y')^2}$$
$$\Rightarrow \sqrt{2gy} = v = \frac{ds}{dt} = \sqrt{1+(y')^2}\,\frac{dx}{dt}$$
$$\Rightarrow dt = \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}}\,dx$$
$$\Rightarrow \int_0^T dt = \int_0^L \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}}\,dx$$

记 $f(y') = \int_0^L \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}}\,dx$

$\Rightarrow$ 变分法 $0 = \frac{d}{dt} f(y+t\varphi)\big|_{t=0} =$

引入 $F(s,t) = \frac{\sqrt{1+t^2}}{\sqrt{2gs}}$，则 $T = \int_0^L F(y,y')\,dx$

$$0 = \frac{d}{dt} f(y+t\varphi) = \frac{d}{dt} \int_0^L F(y+t\varphi,\ y'+t\varphi')\,dx$$
$$= \int_0^L \left( \frac{\partial F}{\partial y}(y,y')\,\varphi + \frac{\partial F}{\partial y'}(y,y')\,\varphi' \right) dx$$
$$= \int_0^L \left( \frac{\partial F}{\partial y}(y,y') - \left( \frac{\partial F}{\partial y'}(y,y') \right)' \right) \varphi\, dx$$
$$\Rightarrow \frac{\partial F}{\partial y}(y,y') = \frac{d}{dx}\left( \frac{\partial F}{\partial y'}(y,y') \right)$$

考虑：
$$\frac{d}{dx}\left( F(y,y') - y'\,\frac{\partial F}{\partial y'}(y,y') \right) = \frac{\partial F}{\partial y}y' + \frac{\partial F}{\partial y'}y'' - y''\frac{\partial F}{\partial y'}(y,y')$$
$$- y'\frac{d}{dx}\left( \frac{\partial F}{\partial y'}(y,y') \right)$$
$$= y'\left( \frac{\partial F}{\partial y}(y,y') - \frac{d}{dx}\left( \frac{\partial F}{\partial y'}(y,y') \right) \right) = 0$$
$$\Rightarrow F(y,y') - y'\,\frac{\partial F}{\partial y'}(y,y') = C$$
$$\Rightarrow \frac{\sqrt{1+(y')^2}}{\sqrt{2gy}} - y'\,\frac{y'}{\sqrt{2gy}\sqrt{1+(y')^2}} = C$$

## 一阶常微分方程

1. 一阶常微分方程 $y' + a(x)y = f(x)$
2. 二阶 $y'' + ay' + by = f(x)$，$(a,b)\in\mathbb{R}^2$ 的情况

技巧：方程两边同乘某个量 / 找守恒量 / 乘积分因子，$f(x)=0$ 或非齐次方程特解。
（Fredholm 二择一，Hilbert）

### $a(x)=a\in\mathbb{R}$，$f(x)=0$ 时

① $y' + ay = 0$

我们知道 $y'=0 \implies y \equiv \text{const.}$

方程两边同乘 $e^{ax}$：$e^{ax}y' + ae^{ax}y = 0$
即 $(e^{ax}y)' = 0 \implies e^{ax}y \equiv \text{const.}$
故 $y = Ce^{-ax}$

· 如何猜出 $e^{ax}$？
设两边同乘 $\varphi$，则 $\varphi y' + a\varphi y = 0$
要使 $\varphi y' + a\varphi y = (\varphi y)'$，须 $\varphi' = a\varphi$，$(\ln\varphi)' = a$

② $y' + ay = f(x)$ 时（$a\in\mathbb{R}$）

已知 $y'=g(x)$ 能解：$y = \int g$
同乘 $e^{ax} \implies e^{ax}y' + ae^{ax}y = e^{ax}f(x)$
即 $(e^{ax}y)' = e^{ax}f(x) \implies e^{ax}y = \int e^{ax}f(x)\,dx$
故 $y = e^{-ax}\int e^{at}f(t)\,dt$

③ $y' + a(x)y = 0$ 时

$\frac{y'}{y} = -a(x)$，$(\ln y)' = -a(x) \implies \ln y = -\int a(t)\,dt$
故 $y = e^{-\int a(t)\,dt}$

④ $y' + a(x)y = f(x)$（一般情形）

令 $\varphi = \int_{x_0}^x a(t)\,dt$，两边同乘 $e^{\varphi}$
则 $(e^{\varphi}y)' = e^{\varphi}y' + a(x)e^{\varphi}y = f(x)$
$\implies y = e^{-\int_{x_0}^x a(t)\,dt}\int_{x_0}^x e^{\int_{x_0}^t a(s)\,ds}f(t)\,dt$

### 例

$$\begin{cases} y' + \dfrac{\cos x}{\sin x}\,y = 1 \\ y\!\left(\dfrac{\pi}{2}\right) = 0 \end{cases}$$

解：$a(x) = \frac{\cos x}{\sin x}$，$\varphi(x) = \int \frac{\cos x}{\sin x}\,dx = \ln(\sin x)$
$\Rightarrow$ 同乘 $e^{\varphi} = \sin x$，得 $(\sin x\cdot y)' = \sin x$
$\Rightarrow \sin x\cdot y = C_0 - \cos x$
$\Rightarrow y = -\frac{\cos x}{\sin x} + \frac{C_0}{\sin x}$
又 $y\!\left(\frac{\pi}{2}\right) = 0$，故 $C_0 = 0$
$\Rightarrow y(x) = -\frac{\cos x}{\sin x}$

### 通解与特解

> [!note] Thm
> 方程 $y' + a(x)y = f(x)$ 的解由齐次方程 $y' + a(x)y = 0$ 的解与方程 $y' + a(x)y = f(x)$ 的一个特解组成，即 $y = Cy_0 + y_*$（$C\in\mathbb{R}$）。

**证明：** 若 $\tilde y$ 为 $y' + a(x)y = f(x)$ 之解，
则 $\tilde y' + a(x)\tilde y = f(x) \Rightarrow (\tilde y - y_*)' + a(x)(\tilde y - y_*) = 0$，
故 $\tilde y - y_*$ 是齐次方程 $y' + a(x)y = 0$ 之解。
即方程的两个解相差 $y_0$ 的常数倍。$\sharp$

## 二阶方程

先考虑：
$$\begin{cases} y' + ay \leq 0 & x\in\,]0,l[ \\ y(0) = 0 \end{cases}$$

则 $(e^{ax}y)' \leq 0$，$e^{ax}y\big|_{x=0} = 0$
$\Rightarrow y(x) \leq 0$

> [!note] Gronwall 不等式
> $$\begin{cases} y' + a(x)y \leq 0 \\ y(0) = y_0 \end{cases}$$
> 令 $\varphi = \int a(t)\,dt$，则 $(e^{\varphi}y)' \leq 0$，$e^{\varphi}y\big|_{x=0} = e^{\varphi(0)}y_0$
> $\Rightarrow y \leq e^{-\varphi(x)+\varphi(0)}y_0$

例：$y = \sin t$，$y' = \cos t$，$y'' = -\sin t$
$\Rightarrow \begin{cases} y'' + y = 0 & t\in\,]0,\pi[ \\ y|_{t=0} = y|_{t=\pi} = 0 \end{cases}$
二阶方程。

### 二阶线性方程（变系数，$0\leq x\leq\pi$）

本次串讲。

$$y''+y=0 \implies y'y'' + yy' = 0 \implies \left( \frac{1}{2}(y')^2 \right)' + \left( \frac{1}{2}y^2 \right)' = 0$$
$$\implies y'^2 + y^2 = C \qquad (\text{“Lyapunov 泛函”})$$

或：
$$y''+y=0 \implies yy'' + y'^2 = 0 \implies (yy')' - (y')^2 + y^2 = 0$$
两边积分 $\implies yy'\big|_0^x = \int_0^x (y')^2\,dt - \int_0^x y^2\,dt$

从而，若 $y(0)=y(\pi)=0 \implies \int_0^{\pi} (y')^2\,dt = \int_0^{\pi} y^2\,dt$（能量估计）

换个方程：
$$\begin{cases} y'' + 1\cdot y = 0 & t\in[0,\pi] \\ y(0) = y(\pi) = 0 \end{cases}$$
同乘 $y'$：$y''y' + y'y = 0$，即 $\frac{1}{2}(y')^2 + \frac{1}{2}y^2 = C$

### 二阶线性常系数方程与特征方程

考虑 $y'' + ay' + b = 0$，$(a,b)\in\mathbb{R}^2$

猜：$y = e^{\lambda t} \implies (\lambda^2 + a\lambda + b)e^{\lambda t} = 0$（$\lambda$ 待定）
$\implies \lambda^2 + a\lambda + b = 0$ —— 特征方程。

若 $\Delta = a^2 - 4b > 0$：$\implies \lambda = \frac{-a\pm\sqrt{a^2-4b}}{2}$
若 $\Delta = a^2 - 4b = 0$：$\implies$ 重根 $\lambda = -\frac{a}{2}$
若 $\Delta < 0$：$\implies$ 共轭复根 $\lambda = \frac{-a\pm\sqrt{4b-a^2}\,i}{2}$

例：
$$\begin{cases} y'' + \mu y = 0, & t\in[0,\pi] \\ y(0) = y(\pi) = 0 \end{cases}$$
特征方程：$\lambda^2 + \mu = 0 \implies \lambda = \pm\sqrt{-\mu}$
$\lambda = 0$ 若 $\mu = 0$
$\lambda = \pm\sqrt{\mu}\,i$ 若 $\mu > 0$

故 $\mu < 0$ 时，$y = C_1e^{\sqrt{-\mu}\,t} + C_2e^{-\sqrt{-\mu}\,t}$，与 $y(0)=y(\pi)=0$ 矛盾（能量估计：$\int_0^{\pi} y'^2\,dt = \int_0^{\pi} y^2\,dt$）
$\implies C_1 = C_2 = 0$。
$\mu = 0$ 时，同上也有 $y = 0$。
$\mu > 0$ 时有非平凡解：
$$y = C_1e^{i\sqrt{\mu}\,t} + C_2e^{-i\sqrt{\mu}\,t} = (C_1+C_2)\cos\sqrt{\mu}\,t + i(C_1-C_2)\sin\sqrt{\mu}\,t$$
$\implies \widetilde{C_1}\cos\sqrt{\mu}\,t + \widetilde{C_2}\sin\sqrt{\mu}\,t$
$\implies y(0) = \widetilde{C_1} = 0$，$y(\pi) = \widetilde{C_2}\sin\sqrt{\mu}\,\pi = 0 \implies \mu = k^2$，$k\in\mathbb{Z}$。
即 $\mu = k^2$ 时有解 $y(t) = C\sin kt$。

### 总结

总结：$y'' + ay' + by = 0$
特征方程：$\lambda^2 + a\lambda + b = 0$

$\Delta > 0 \Rightarrow y = C_1e^{\lambda_1 t} + C_2e^{\lambda_2 t}$
$\Delta = 0 \Rightarrow y = C_1e^{-\frac{a}{2}t} + C_2te^{-\frac{a}{2}t}$
$\Delta < 0 \Rightarrow y = C_1e^{\lambda_1 t} + C_2e^{\lambda_2 t} = e^{-\frac{a}{2}t}\left( \tilde C_1\cos\frac{\sqrt{4b-a^2}}{2}t + \tilde C_2\sin\frac{\sqrt{4b-a^2}}{2}t \right)$

> [!note] Prop
> $y'' + ay' + by = f(x)$ 解的形式也是通解 + 特解。

> [!exercise] exer
> ① 求 $\inf \frac{\int_0^1 f'^2 + y^2}{\int_0^1 f^2}$；求 $\frac{y''}{\sqrt{1+(y')^2}} + 1 = 0$ 的 Liapunov 函数。
> ② 解 $\begin{cases} y' + a(x)y \leq f(x) \\ y(0) = y_0 \end{cases}$，求 $y$ 的估计。

> [!note] Th
> $$\begin{cases} y'' + ay' + by = 0 \\ y(t_0) = x_0,\ y'(t_0) = y_0 \end{cases}$$
> 有唯一解。

**证明：** 若有两解 $y_1, y_2$。
令 $h(x) = y_1(x) - y_2(x)$，则
$$\begin{cases} h'' + ah' + bh = 0 \\ h(t_0) = 0,\ h'(t_0) = 0 \end{cases}$$
令 $\omega(x) = h^2 + h'^2$，
则 $\omega'(x) = 2hh' + 2h'h'' = 2hh' + 2h'(-ah' - bh)$
$$\leq (h^2 + h'^2)\cdot C \qquad (C\in\mathbb{R}^+)$$
$$\Rightarrow \begin{cases} \omega' \leq C\omega \\ \omega \geq 0 \\ \omega(t_0) = 0 \end{cases}$$
$\Rightarrow \omega \equiv 0$。$\sharp$

## 解方程

解方程：$y'' + a(x)y' + b(x)y = 0 \quad (*)$

设 $(*)$ 有两个解 $y_1, y_2$。
令
$$w = \begin{vmatrix} y_1 & y_2 \\ y_1' & y_2' \end{vmatrix} = y_1y_2' - y_2y_1'$$
则 $w' = y_1'y_2' + y_1y_2'' - y_2'y_1' - y_2y_1'' = y_1y_2'' - y_2y_1''$
$= y_1(-a(x)y_2' - b(x)y_2) - y_2(-a(x)y_1' - b(x)y_1) = -a(x)w$。

题

几个常见方法：

1. 可分离变量：$\frac{dx}{dy} = \frac{f(x)}{g(y)}$
2. 齐次 $\frac{dy}{dx} = \frac{P(x,y)}{Q(x,y)}$ 是 $n$ 次齐次，$= \varphi\!\left(\frac{y}{x}\right)$
令 $u = \frac{y}{x} \implies y' = xu' + u = \varphi(u)$，可解出 $u$。

## Picard–Lindelöf 定理

> [!note] Th (Picard–Lindelöf)
> $$\begin{cases} y' = f(x,y) \\ y(x_0) = y_0 \end{cases}$$
> $f$ 定义在矩形 $(x_0-a,\ y_0-b)\times(x_0+a,\ y_0+b)$ 内；$f(x,y)$ 在该矩形上连续，且 $\forall (x,y_1),(x,y_2)$，
> $$|f(x,y_1) - f(x,y_2)| \leq L|y_1 - y_2|.$$

> [!note] Prop
> 设 $(f_n)_{n\geq 1}$ 为一族 $C^0([a,b])$ 上的函数。设 $(f_n)$ 一致收敛到 $f$，则 $f$ 连续。

**Th 的证明：**

$$y(x) = y_0 + \int_{x_0}^x f(t, y(t))\,dt$$

定义算子 $T$：$T\varphi := y_0 + \int_{x_0}^x f(t, \varphi(t))\,dt$，即要解 $Ty = y$。

令 $\varphi_0 = y_0$，$\varphi_1 = T\varphi_0$，$\cdots$，$\varphi_{n+1} = T\varphi_n$。

则 $|\varphi_n - \varphi_0| \leq \int_{x_0}^x f(t, y_n)\,dt \leq M|x - x_0|$

$$|\varphi_1 - \varphi_0| \leq \int_{x_0}^x |f(t,\varphi_0) - f(t,y_0)|\,dt \leq L\int_{x_0}^x |\varphi_0 - y_0|\,dt \leq \frac{LM}{2}|x-x_0|^2$$
$$|\varphi_{n+1} - \varphi_n| \leq \frac{L^nM}{(n+1)!}|x-x_0|^{n+1}$$
$\Rightarrow \{\varphi_n\}$ 一致收敛到 $\varphi$
$\Rightarrow T\varphi = \varphi$，即 $\varphi$ 是方程的解

若 $y_1, y_2$ 均为 (1) 之解，
则 $|y_1 - y_2| \leq \int_{x_0}^x |f(t,y_1(t)) - f(t,y_2(t))|\,dt \leq L\int_{x_0}^x |y_1(t) - y_2(t)|\,dt$

令 $F = \int_{x_0}^x |y_1(t) - y_2(t)|\,dt$，则 $F' \leq LF \Rightarrow (e^{-Lx}F)' \leq 0$
