# 勒让德多项式 (Legendre Polynomials)

> [!question] 本页要回答什么？
> 三角系不是唯一的选择。换一组完备正交系,整套 Fourier 展开理论是否照样成立?

> 讲义 §5.4。**讲义原话:"本节是讲个故事而已,没有什么需要记住的。"** 本页按"故事"的定位整理——知道结构与平行性即可。

## 1. 定义

在 $[-1,1]$ 上定义
$$L_n(x) = \frac{d^n}{dx^n}(x^2-1)^n,\qquad n=0,1,2,\dots$$

1. **易见 $L_n$ 是多项式,且 $\deg L_n=n$**。进而任何一个 $n$ 次多项式 $P$ 一定可以写成 $L_n$ 的线性组合。
2. **正交性**。计算
   $$A_{mn} = \int_{-1}^{1}\frac{d^m}{dx^m}(x^2-1)^m\cdot\frac{d^n}{dx^n}(x^2-1)^n\,dx.$$
   只要不停地做**分部积分**,就可以证明
   $$A_{mn} = \delta_{mn}\frac{(n!)^2\,2^{2n+1}}{2n+1}.$$
   进而若定义 $\hat L_n = \frac{L_n}{\|L_n\|}$，就得到一组**正交系**。
3. **完备性为什么成立?** 如果理解了 Fourier 对应的证明,这个不困难(同样的思路:三角多项式一致逼近的位置,这里由多项式的逼近性质承担)。
4. 这组基实际上可以理解成是多项式序列 $1,x,x^2,\dots$ 通过 **Gram–Schmidt 正交化**得到的。

## 2. 与三角系的平行:特征函数视角

给定这些自然就要一整套类似 Fourier 的展开理论。为什么**三角函数**组成的正交基可以用来求解方程(引言的分离变量法)?还因为它们是下面这个**特征值问题**的解:
$$u''(x)+\lambda u(x) = 0\qquad(\text{要求 } u \text{ 是 } 2\pi \text{ 周期的}).$$

类似地,$L_n$ 也恰好是某个特征值问题的特征函数:
$$\bigl((1-x^2)u'(x)\bigr)'+\lambda u(x) = 0,\qquad x\in(-1,1),$$
其中要求 $u$ 在端点 $\pm1$ 处**有界**(正则)。此时特征值是 $\lambda_n=n(n+1)$，对应特征函数是 $L_n$。展开写就是
$$(1-x^2)L_n''-2xL_n'+n(n+1)L_n = 0.$$

> [!tip] 验证
> 对 $y=(x^2-1)^n$ 求一次导得 $(x^2-1)y'=2nxy$，两边用 **Leibniz 公式**求 $n+1$ 次导即可。

**平行性总结**(这是全节最值得记的一句话):

| | 三角函数系 | 勒让德多项式 |
|---|---|---|
| 所在区间 | $[-\pi,\pi]$ | $[-1,1]$ |
| 特征值问题 | $u''+\lambda u=0$，**周期**边条件 | $\bigl((1-x^2)u'\bigr)'+\lambda u=0$，**正则(端点有界)**边条件 |
| 特征值 | $n^2$ | $n(n+1)$ |
| 为什么两两正交 | 自伴算子的不同特征值对应特征函数正交 | 同一个原因 |

> **这与三角函数的情形完全平行**:三角函数是周期边条件下 $u''+\lambda u=0$ 的特征函数,$L_n$ 则是正则边条件下 $\bigl((1-x^2)u'\bigr)'+\lambda u=0$ 的特征函数;这同样解释了为什么 $L_n$ 两两正交。

## 3. 历史注记(讲义 §5.5 节选)

我们在这里把 Legendre 多项式作为 Fourier 展开的推广,这是**按数学结构安排的讲法**。历史上,Legendre 多项式出现得很早:

- **Legendre 在 1783 年提交的关于均匀球状天体引力的研究中引入了这类函数**，论文于 1785 年出版。当时的具体问题是:怎样计算这类天体对外部质点的引力。我们今天用正交化来构造这些多项式,**原来的发现过程则来自天体力学中的计算**。
- 到了 **1830 年代,Sturm 和 Liouville** 开始系统研究一大类二阶微分方程及其函数展开。Liouville 1836 年论文开头考虑的就是**非均匀细杆的热传导**:材料性质随位置变化,分离变量以后所需的函数也随之改变。用今天的语言说,在适当的边界条件下,**微分算子的自伴性**使不同特征值对应的特征函数正交;至于能否用它们展开一般函数,还需要证明**完备性**。
- 这样,三角函数、Legendre 多项式以及许多别的函数系,就有了**共同的研究方向:从方程寻找合适的正交系,再研究它的展开理论。**

> 这就是**Sturm–Liouville 理论**的起源——它把"Fourier 展开"从"三角函数的特殊性质"提升为"二阶自伴微分算子的一般理论"。以后在球面上展开(球谐函数)时,轴对称情形又会归结为 $P_n(\cos\theta)$，其中 $P_n$ 是通常归一化的 Legendre 多项式。

## 4. 与本 wiki 定位

这是"推广"的故事:三角系 → Legendre 多项式 → (将来的)球谐函数、Sturm–Liouville 一般理论。核心结论是**结构平行性**:换一组正交系,同样的"内积 → 投影 → 最佳逼近 → 完备性 → Parseval 等式"框架照搬。

- Gram–Schmidt 过程是线性代数的已有内容,这里是它的函数空间版本。
