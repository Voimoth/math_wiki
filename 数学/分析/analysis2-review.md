# 分析II(下) 复习:因果链地图

## 全册主线(四章一条链)

```
第1章 幂级数 ──► 函数项级数的最重要特例(白嫖前册),新增"收敛半径"
   │
第2章 广义积分 ──► 级数的连续版:Σ→∫,判别法平行移植
   │
第3章 含参变量积分 ──► 极限交换的升级战场 + 控制收敛定理(大统一)

```

**口诀**:级数 → 积分 → 极限交换 → 解方程,每章是上章工具在更大舞台的重演。

## 第1章 幂级数:三个核心结构

1. **Abel 引理**:$(a_n z_0^n)$ 有界 ⟹ $|z|<|z_0|$ 时绝对收敛。证明=$|a_nz^n|\le C(|z|/|z_0|)^n$ 几何级数比较。**收敛区域必然是圆盘的原因**。
2. **收敛半径**:$R = 1/\limsup|a_n|^{1/n}$;边界 $|z|=R$ 行为不定(例1.6 三种情况);$R=0$ 或 $\infty$ 都可能。
3. **内闭一致收敛 ⟹ 和函数光滑 + 逐项求导/积分免费**(Thm 1.17-1.19)。对比 6.21:一般函数列要验证导数一致收敛,**幂级数自动满足**(导数也是同半径幂级数)。逐项求导/积分是算和函数的两大武器(例1.20 log(1+x))。

## 第2章 广义积分:判别法"连续化"

| 级数 | 广义积分 |
|---|---|
| 比较/Abel/Dirichlet 判别法 | 同款(参数换成函数) |
| 绝对收敛⟹收敛 | 同款 |

关键:收敛性 vs 绝对收敛性分开判断(例 $\int_1^\infty \sin x/x$ 条件收敛)。流程:先看绝对,再看条件。

## 第3章 含参变量积分 + 控制收敛定理

### Leibniz 法则
$f, \partial_t f$ 连续 ⟹ $\frac{d}{dt}\int f(x,t)dx = \int \partial_t f(x,t)dx$(6.21 的翻版)。

### ⭐ 控制收敛定理(3.29,全册最重要)—— 详见下方专题

### Gamma 函数
$\Gamma(s)=\int_0^\infty t^{s-1}e^{-t}dt$;$\Gamma(s+1)=s\Gamma(s)$;$\Gamma(n+1)=n!$。**阶乘的连续化身**,与 $\sum z^n/n!$ 相映成趣。

## 第4章 ODE:总检阅

| 内容 | 用到的工具 |
|---|---|
| 一阶线性 | 积分因子 |
| 二阶常系数 | 特征方程 $e^{\lambda x}$ |
| 方程组 $Y'=AY$ | **矩阵指数 $e^{tA}=\sum t^nA^n/n!$(幂级数!)** |
| 二阶理论 | Wronskian、线性代数 |

彩蛋:$e^{tA}$ 收敛性靠 $\sum\|A\|^n/n!$(分析II-1 第5章)——**ODE 串起整个学期**。

# 专题:控制收敛定理(当时没给证明,这里补直觉)

## 定理(函数列形式)
$f_n \to f$ 逐点 + $\exists$ 可积 $g$,$|f_n|\le g$ ⟹ $\int f_n \to \int f$。

## 为什么需要:尖峰反例
$f_n = n\cdot\mathbf{1}_{(0,1/n)}$:逐点收敛到 0,但 $\int f_n = 1$。逐点收敛不控制"峰高×峰宽",面积可以逃逸。**控制条件排除这类灾难**。

## 与 6.19 的关系
- 6.19:一致收敛(强条件);控制收敛:逐点 + 控制(弱条件),结论相同。
- 控制收敛是 6.19 的"升级版/大统一",四种形式(函数列/级数/参数连续/参数极限)。

## 证明思想(懂思想即可,Riemann 版不要求会写)
1. $|f|\le g$ 故 $f$ 可积;
2. 尾巴:$\int_{I\setminus[-M,M]}g$ 任意小;
3. 核心:被 $g$ 罩住 ⟹ $f_n$ 在 $[-M,M]$ 上**几乎一致收敛**(Egorov 思想,Riemann 简化版):除去总长任意小的坏集合,其余一致收敛;
4. 好部分用一致收敛,坏集合用 $|f_n-f|\le 2g$ 控制,ε/3 拼接。

**Slogan**:逐点收敛 + 控制 = 几乎一致收敛 = 可以交换极限。

## 为什么当时没给证明
完整证明需要 Lebesgue 测度论(坏集合测度、绝对连续、Egorov 定理)。Riemann 框架下是"借来的工具",实变函数课还账(Lebesgue 版一行证明)。
