# 知识库索引

按学科组织的 Obsidian vault。每个学科目录内有一份 `_索引.md`；课程内容与概念页由该索引分节列出。

## 数学与物理答疑归档

用户提出的数学和物理问题，凡包含可复用的定义、推理、证明要点、方法判断、例子或易错点，回答后直接整理到对应课程的 `概念/` 页，不询问是否写入；用户原始讲义和课程笔记仍只放在 `笔记/`。

写作格式（问题驱动开篇、callout 分层、编号递进、禁止 emoji）原记录在 `共享/SCHEMA.md`。该文件已于 2026-09-11 删除——其内容与 vault 现状不符（一半是 llm-wiki 模板残留），有效部分改由维护者的技能库保存。
