# 中法班课程笔记（USTC 2025 级）

这是 USTC 中法班的课程笔记，用 Obsidian 维护，按「学科 → 课程」组织。以数学正课为主，内容较丰富的习题课另立；
老师发讲义的课按讲义整理，其余按课堂手写笔记整理。笔记与概念页主要由 DeepSeek 生成，少量内容来自 GPT 与 GLM，
再经人工核对与修改；错误难免，发现具体错误欢迎开 issue 指出。

## 目录结构

```
数学/{分析,代数,概率}/<课程>/
    概念/        概念页：一概念一文件，agent 维护的知识库
    笔记/        课堂笔记：NN-章名.md，00-总览.md 是入口；正课/习题课分目录
    _索引.md      课程索引（学科级 _索引.md 汇总）
物理/理论力学/     扁平结构：概念页直接放课程目录
共享/记号约定.md   全库记号标准
log.md            变更日志（追加式）
```

## 怎么读

- 入口是各学科的 `_索引.md`：`数学/分析/_索引.md`、`数学/代数/_索引.md`、`数学/概率/_索引.md`、`物理/理论力学/_索引.md`。
- 每门课的「学习路径」给主线的因果站序（群论、点集拓扑、Fourier、变分法），适合从头过一遍。
- 课堂笔记从各目录的 `00-总览.md` 进，按 `NN-章名` 顺序读。
- 概念页开头是「为什么需要它」，接着定义、证明要点、例子与陷阱，页尾「相关概念」指向因果链的下一步。

## 约定

- **概念页与笔记分离**：概念页只写概念本身（定义、动机、证明要点、概念性例子与陷阱），不夹带题号、题目数值与凑题过程。
- **一概念一文件**：同一概念只在最早出现的那门课保留一页，别门课以链接引用。
- **记号统一**：全库标准见 `共享/记号约定.md`（经典群正体、对称群哥特体、转置左上 $t$、自然常数正体 $\mathrm{e}$ 等），分课差异有登记表。
- 不使用 emoji。

## 课程与教师

**大一上**：分析 I（陈世炳）、代数 I（梁永祺 / 曹培根）；力学、热学（廖源，未整理）。

**大一下**：分析 II（殷浩）、代数 II（梁永祺）；电磁学（林箐，未整理）。

**大一暑假**：概率（孙晨旻、陈林晓，课程名「分析与代数基础」）。

**大二上（更新中）**：分析 III（殷浩）、代数 III（Marc Rosso，Bernard Keller / 许金兴）、理论力学（袁业飞）、电动力学（肖建元）。

## 工具

维护这个库用的 AI 技能与 Neovim 配置：[math-toolkit](https://github.com/Voimoth/math-toolkit)。

配置单独放出来，是因为同一份 Markdown 在不同编辑器里的 LaTeX 渲染差别很大（行内公式定界符、反斜杠转义、MathJax 宏各有各的脾气）；
照这套配置能得到与笔记一致的显示效果，不想折腾环境可以直接照抄其中的 `nvim/`。
