这是USTC中法班25级的课程笔记(持续更新中).
主要整理了数学正课的笔记, 以及一些内容比较丰富的习题课. 部分课程老师会发送自己的讲义, 则按讲义整理; 其他的由自己的笔记整理.
整理工作均由ai完成.

具体课程安排如下:

__大一上:__
- 分析I(陈世炳)
- 代数I(梁永祺/曹培根)
- 力学 热学(廖源) (没整理, 因为我没记笔记)

__大一下:__
- 分析II(殷浩)
- 代数II(梁永祺)
- 电磁学(林箐) (跟力学热学一桌)

__大一暑假:__
- 概率(孙晨旻, 陈林晓) (学名叫"分析与代数基础")

__大二上(更新中):__
- 分析III(殷浩)
- 代数III(Marc ROSSO, Bernhard Keller/许金兴)
- 理论力学(袁业飞) 电动力学(肖建元)
