从凸集构造范数：Minkowski 泛函
设 V 为实向量空间。我们将证明如何从适当的凸集出发构造范数，这是
泛函分析中的基本构造。
对集合 C 的要求
称子集 C ⊂ V 为容许集（admissible set），若满足以下四个条件：
(i) 凸性（Convexity）：对任意 x, y ∈ C 及 t ∈ [0, 1]，有
tx + (1 − t)y ∈ C;
(ii) 平衡性（Balancedness）：对任意 x ∈ C 及满足 |λ| ≤ 1 的标量
λ ∈ R，有
λx ∈ C;
(iii) 吸收性（Absorbing）：对任意 x ∈ V ，存在 t > 0 使得
x ∈ tC := {ty : y ∈ C};
(iv) 有界性（Boundedness）：C 不包含任何过原点的非平凡直线，即
若 x 6 = 0，则存在 λ0 > 0 使得 λx /∈ C 对所有 |λ| ≥ λ0 成立。
Minkowski 泛函的定义
设 C ⊂ V 为容许集。定义映射 ‖ · ‖C : V → [0, +∞) 为
(1.1) ‖x‖C := inf{t > 0 : x ∈ tC}, x ∈ V.
称 ‖ · ‖C 为关于 C 的 Minkowski 泛函（Minkowski functional）或规
范函数（gauge function）。
由吸收性条件 (iii)，对任意 x ∈ V ，集合 {t > 0 : x ∈ tC} 非空，故
‖x‖C 良定义且有限。作为习题：验证如此定义的 ‖·‖

1.1.2. 范数决定的距离. 暂时还不打算引入抽象的距离空间定义，只是说在赋
范向量空间上有一个距离函数: d : E × E → R+
d(x, y) := ‖y − x‖ .
不难看出它满足如下的简单性质：
• d(x, y) = d(y, x);
• d(x, y) ≥ 0，取等号当且仅当，x = y;
• d(x, y) + d(y, z) ≥ d(x, z).
以后这几条就是距离的抽象定义。配上这个距离，就真的三角形两边之和大于
(=) 第三边了。法国书上有个有趣的注意：在抽象的赋范向量空间中，说两点
之间线段最短，un plus court chemin entre deux points est la ligne droite. 思
考题：为什么是不定冠词？
下面这条叫：“平移不变性”。对于赋范向量空间上定义的距离是对的，但
是不是一般距离空间可以谈的（不是对不对的问题，而是它们都没法定义“平
移”）：
d(x, y) = d(x + z, y + z), ∀x, y, z ∈ E.

用这个性质要小心 ，毕竟不再是传统的距离函数，比如 d(A, B) = 0 也不是说
