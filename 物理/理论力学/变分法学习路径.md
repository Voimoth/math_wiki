# 变分法学习路径

变分法只回答一个问题：**某个积分取极值时，被积函数里的那条曲线满足什么方程。**

## 因果链

最小作用量原理 → 变分（函数空间方向导数）→ 分部积分搬导数 → 变分法基本引理 → 欧拉-拉格朗日方程 → 全导数不改变动力学 → Beltrami 恒等式（不显含自变量 ⇒ 首次积分）→ 费马原理 / 最速降线 / 测地线方程 → 对称性与守恒量

## 概念清单

### 基础

- [[变分]] — 变分 = 函数空间上的方向导数，与普通导数的区别
- [[变分与积分号的交换]] — 交换的到底是什么、需要什么条件
- [[等时变分]] — 扰动只加在函数值上，$\delta t = 0$
- [[最小作用量原理]] — $\delta S = 0$ 的陈述与"最小"一词的准确性

### 方程

- [[欧拉-拉格朗日方程]] — 分部积分 + 基本引理；含高阶导数的符号规律
- [[全导数不改变动力学]] — 拉格朗日量不唯一，以及相关的三个陷阱

### 一阶积分

- [[Beltrami 恒等式]] — 被积函数不显含自变量时直接得守恒量
- [[仿射参数]] — 测地线方程的参数重标定不变性

### 应用

- [[费马原理]] — 光程泛函；折射率中的因子 2
- [[最速降线]] — 摆线；初速不为零只改变起点
- [[测地线方程]] — 克里斯托弗联络；球面测地线为大圆

## 三句话记住

1. 变分是对参数 $\varepsilon$ 求导，$t$ 不动；所谓"交换"是 $\partial_\varepsilon$ 与 $\partial_t$ 交换。
2. 全部计算归约为：链式展开 → 分部积分把导数搬走 → 边界项归零 → 基本引理。
3. 被积函数缺哪个变量，就对哪个变量取首次积分（Beltrami/循环坐标），不必解二阶方程。
