## 分块复习计划

### A. 拉格朗日力学（快速过）

- 变分法、欧拉–拉格朗日方程
- 诺特定理、循环坐标、守恒量
- 有心力、有效势、轨道方程
- 微振动、简正模

**目标**：保证计算速度，不出符号错误。

### B. 哈密顿正则方程

- 勒让德变换：从 `L(q, q̇)` 到 `H(q, p)`
- 正则方程：
  $$
  \dot q_\alpha = \frac{\partial H}{\partial p_\alpha}, \quad
  \dot p_\alpha = -\frac{\partial H}{\partial q_\alpha}
  $$
- 修正的哈密顿原理：相空间变分，`q` 与 `p` 独立
- 循环坐标、劳斯方程

**必练**：hw9 之外的任何 `L → H → 正则方程` 的完整流程。

### C. 正则变换

- 判定条件：存在 `F` 使 `p\,dq - P\,dQ = dF`
- 四类生成函数 `F_1`–`F_4` 的变量与求导关系
- 新哈密顿量：`K = H + \partial F/\partial t`
- 几何意义：保辛 `dP \wedge dQ = dp \wedge dq`，Jacobi 行列式为 1（与新辛形式约定一致）

**必练**：2026-01-A 第四题（`F_1 = \frac{1}{2}\omega q^2 \cot 2\pi Q`）。

### D. 泊松括号

- 定义：
  $$
  \{F, G\} = \sum_\alpha \left(
  \frac{\partial F}{\partial q_\alpha}\frac{\partial G}{\partial p_\alpha} -
  \frac{\partial F}{\partial p_\alpha}\frac{\partial G}{\partial q_\alpha}
  \right)
  $$
- 基本括号：`{q_α, p_β} = δ_αβ`，`{q_α, q_β} = {p_α, p_β} = 0`
- 性质：双线性、反对称、Leibniz、Jacobi
- 运动方程：`df/dt = ∂f/∂t + {f, H}`
- 泊松定理：两个运动积分的括号仍是运动积分

**必练**：2026-01-A 第三题（二维谐振子的 `A_ij` 与 `S_i`）。

### E. 哈密顿–雅可比方程

- `H(q, \partial S/\partial q) + \partial S/\partial t = 0`
- 不显含 `t` 时：`S = -Et + W(q)`
- 循环坐标导致分离变量
- 由 `\partial S/\partial C_i = β_i` 得到运动方程的积分形式

**必练**：2026-01-A 第五题（拉格朗日陀螺的 `S` 与积分形式运动方程）。

### F. 相空间几何（几何题重点，中法班需更数学化）

- 相空间 = 余切丛 `T^*M`
- 典范一形式 `θ = p_i dq^i`，辛形式 `ω = dθ = dp_i \wedge dq^i`
- 辛流形：闭、非退化的 2-形式
- Darboux 定理：局部总能写成 `ω = dp_i \wedge dq^i`
- 哈密顿向量场：`ω(·, X_H) = dH`，即 `ι_{X_H} ω = -dH`
- 相流保辛：`L_{X_H} ω = 0`（用 Cartan 公式证明）
- 刘维尔定理：相空间体积不变
- 扩充相空间：`θ^1 = p_i dq^i - H dt`，`dθ^1 = ω - dH \wedge dt`，涡线即相轨迹
- 庞加莱–嘉当积分不变量
- 泊松括号与李代数：`{F,G} = ω(X_G, X_F)`，`[X_F, X_G] = X_{\{G,F\}}`

**必练**：hw9 Q6、Q7；相空间中的辛几何讲义第 2、4、5、6、8 章。

### G. 刚体（与 H-J 结合）

- 欧拉角、运动学方程
- 转动惯量张量、惯量主轴
- 欧拉陀螺：三个守恒量、两个圆锥
- 拉格朗日陀螺：哈密顿量、有效势、章动/进动/自转

**必练**：2026-01-A 第五题；hw8 Q1–Q3。

### H. 作用量–角变量（hw9 补充）

- 作用变量 `I` 的定义（对周期运动积分 `I = (1/2π) ∮ p\,dq`）
- 角变量 `φ` 及其与直角坐标的关系
- 可积系统与不变环面

**必练**：hw9 Q5。

## 几何题可能的具体形态

1. **保辛 / 保面积**：证明某变换是正则变换，或验证 `dp ∧ dq = dP ∧ dQ`。
2. **刘维尔定理的证明**：用 `L_{X_H} ω = 0` 或相空间体积守恒。
3. **哈密顿向量场**：由 `ω(·, X_H) = dH` 写出 `X_H` 的坐标表达式。
4. **扩充相空间**：验证 `θ^1 = p\,dq - H dt` 的涡线方向就是正则方程。
5. **泊松括号的几何**：把 `{F, G}` 解释为 `ω(X_G, X_F)`。

## 学习提示

- 中法班考试更偏数学，几何题可能要你**从抽象定义出发**（如由 `ω = dθ` 证 Darboux 坐标存在、由 `ω(·, X_H) = dH` 写 `X_H`、用 Cartan 公式证 `L_X ω = 0`），而不只是验证具体变换保辛。
- 几何题的常见套路是“把代数结论翻译回辛形式”：先算 `dp ∧ dq`，再和 `dP ∧ dQ` 比较；或把正则方程写成 `ω(·, X_H) = dH`。
- 2026-01-A 卷是其他班的题，风格可参考，但不要把它的难度和题型当成中法班的真题来押。
- hw9 的 Q5–Q7 是课堂上没系统讲但作业要求自学的内容，必须单独补，尤其是 Q6、Q7 的辛几何语言。
