# 变分法与最小作用量原理（Calculus of Variations, principe de moindre action）

> [!question] 问题 0
> 变分和普通导数有什么区别？为什么变分可以和积分号互换？最小作用量原理 $\delta S = 0$ 凭什么能挤出一个微分方程？

## 1. 变分 = 函数空间上的方向导数

平常的导数作用于数：
$$f: \mathbb{R} \to \mathbb{R}, \qquad f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
增量 $h$ 是**数**。

泛函的输入本身是函数、输出是数，例如作用量
$$S[x] = \int_{t_1}^{t_2} L\big(x(t), \dot{x}(t), \ddot{x}(t)\big) \, dt .$$
此时"$x$ 加一个增量"应当是**加一整个函数**。取固定的扰动方向 $\eta$，令
$$x_\varepsilon(t) = x(t) + \varepsilon \, \eta(t),$$
其中 $\varepsilon$ 是普通实数（走多远），$\eta$ 是一条固定的函数（往哪个方向走）。于是泛函退化为关于 $\varepsilon$ 的普通一元函数
$$S(\varepsilon) = \int_{t_1}^{t_2} L\big(x + \varepsilon\eta, \; \dot{x} + \varepsilon\dot{\eta}, \; \ddot{x} + \varepsilon\ddot{\eta}\big) \, dt ,$$
变分即在该 $\varepsilon$ 上求普通导数并取 $\varepsilon = 0$：
$$\delta S := \left. \frac{d}{d\varepsilon} S(\varepsilon) \right|_{\varepsilon = 0} .$$

> [!note] 定义（变分导数）
> 严格地说，变分是泛函在方向 $\eta$ 上的**方向导数**。因为函数空间是无穷维的，无法谈"梯度向量"，只能对每个方向 $\eta$ 谈方向导数。常用的等价写法
> $$\delta S = \int \frac{\delta S}{\delta x(t)} \, \eta(t) \, dt ,$$
> 其中 $\frac{\delta S}{\delta x(t)}$ 称为**变分导数**（dérivée variationnelle），即泛函的梯度的分量。

> [!tip] 想法：为什么是一个数能挤出一整个方程
> 普通极值只有一个方程 $f'(x) = 0$；变分条件 $\delta S = 0$ 却是
> $$\delta S = 0 \quad \text{对**所有**方向 } \eta \text{ 成立} \iff \frac{\delta S}{\delta x(t)} = 0 \quad \text{对**所有** } t \text{ 成立} .$$
> 左侧是"一个数等于零"，右侧是"逐点的函数等于零"——后者才是一整个微分方程。这才是最小作用量原理能给出动力学方程的原因。

## 2. 与普通极值的对照

| | 一元微积分 | 变分法 |
|---|---|---|
| 变量 | $x \in \mathbb{R}$ | $x(\cdot)$ 属于函数空间 |
| 增量 | $h$ | $\eta(t)$ |
| 一阶条件 | $f'(x) = 0$ | $\delta S = 0$ 对所有 $\eta$ |
| 条件形态 | 一个方程 | 一个微分方程（逐点） |
| 二阶条件 | $f'' > 0$ | 二阶变分 $\delta^2 S$ 定号（本课程不涉及） |

## 3. 为什么"可以和积分号互换"

> [!warning] 陷阱：这里根本没有"变分与积分互换"这回事
> 积分号从头到尾都在外面。真正被交换的是 $\frac{\partial}{\partial\varepsilon}$ 与 $\frac{\partial}{\partial t}$（或 $\int dt$）——求导变量是**参数 $\varepsilon$**，积分变量是 **$t$**，两者互相独立。

固定 $t$，则 $\varepsilon \mapsto L(x + \varepsilon\eta, \dot{x} + \varepsilon\dot{\eta})$ 是复合函数，链式法则给出
$$\left. \frac{\partial}{\partial\varepsilon} L\big(x + \varepsilon\eta, \dot{x} + \varepsilon\dot{\eta}\big) \right|_{\varepsilon = 0} = L_x \, \eta + L_{\dot{x}} \, \dot{\eta} ,$$
该等式对**每个固定的 $t$** 都成立，因而积分也成立（积分是求和的极限）：
$$\left. \frac{d}{d\varepsilon} S(\varepsilon) \right|_{\varepsilon = 0} = \int_{t_1}^{t_2} \big( L_x \eta + L_{\dot{x}} \dot{\eta} \big) \, dt .$$

> [!note] 换序所需的条件
> $$\frac{d}{d\varepsilon} \int_{t_1}^{t_2} L \, dt = \int_{t_1}^{t_2} \frac{\partial L}{\partial\varepsilon} \, dt$$
> 本质上就是分析 III 的**积分与参数求导交换**（把 $\varepsilon$ 看作参数），需要：
> 1. 积分区间 $[t_1, t_2]$ 有限；
> 2. $\frac{\partial L}{\partial\varepsilon}$ 作为 $(t, \varepsilon)$ 的函数连续，或被一个可积函数控制（控制收敛）。
>
> 物理问题里 $L$ 光滑、区间有限，条件自动满足，故课上不再提；一旦遇到无界区间或奇异 $L$，这一步就是真正需要检查的地方。

## 4. $\delta$ 的三条运算规则

把 $\delta$ 看作"对 $\varepsilon$ 求导再令 $\varepsilon = 0$"：

| 规则 | 内容 | 理由 |
|---|---|---|
| 线性 | $\delta(L_1 + L_2) = \delta L_1 + \delta L_2$ | 导数线性 |
| 链式 | $\delta L = L_x \delta x + L_{\dot{x}} \delta \dot{x} + L_{\ddot{x}} \delta \ddot{x}$ | 全微分/链式法则 |
| 与时间导数交换 | $\delta\!\left( \frac{dx}{dt} \right) = \frac{d}{dt}(\delta x)$ | 混合偏导相等 |

第三条的验证：
$$\delta \dot{x} = \left. \frac{d}{d\varepsilon} \left( \frac{dx}{dt} + \varepsilon \frac{d\eta}{dt} \right) \right|_{\varepsilon = 0} = \frac{d\eta}{dt} = \frac{d}{dt}(\delta x) ,$$
依据是 $x_\varepsilon = x(t) + \varepsilon\eta(t)$ 中 $\varepsilon$ 与 $t$ 为独立变量，故
$$\frac{\partial^2 x_\varepsilon}{\partial\varepsilon \, \partial t} = \frac{\partial^2 x_\varepsilon}{\partial t \, \partial\varepsilon} .$$

## 5. 等时变分：$t$ 不参与变分

> [!note] 等时变分（variation isochrone）
> 扰动只加在函数值上、不加在时间上：$x_\varepsilon(t) = x(t) + \varepsilon\eta(t)$（而**不是** $x(t + \varepsilon\eta)$）。因此
> $$\delta t = 0, \qquad \delta t_1 = \delta t_2 = 0 .$$

由此，$t$ 在变分中永远只是一个**标签/参数**。对显含时间的拉格朗日量 $L(q, \dot{q}, t)$，
$$\delta L = L_q \, \delta q + L_{\dot{q}} \, \delta\dot{q} ,$$
其中 $\frac{\partial L}{\partial t}$ **不出现任何贡献**——因为 $t$ 那一槽压根没有动。

> [!warning] 陷阱：$\delta t = 0$ 不是额外假设
> 它是"等时变分"这个定义的直接推论。与之相对的是**非等时变分**（$\delta t \neq 0$），需额外出现 $L\,\delta t$ 一类的项；本课程不涉及。

## 6. 全导数不影响动力学

$$\delta\!\left( \frac{df(q,t)}{dt} \right) = \delta\big( f_q \, \dot{q} + f_t \big) = \frac{d}{dt}\big( f_q \, \delta q \big) ,$$
它在作用量中的贡献
$$\int_{t_1}^{t_2} \frac{d}{dt}\big( f_q \, \delta q \big) \, dt = \Big[ f_q \, \delta q \Big]_{t_1}^{t_2} = 0$$
因为两端 $\delta q = 0$，边界项自动消失。这就是"拉格朗日量不唯一"（加上任意全导数不改变动力学方程）的根源。

## 7. 分部积分：变分法的引擎

单导数情形 $\delta S = \int (L_x \eta + L_{\dot{x}} \dot{\eta}) \, dt$。其中 $\dot{\eta}$ 不能直接令系数为零，因为 $\eta$ 与 $\dot{\eta}$ 由同一个 $\eta$ 决定、并不独立。做法是把导数从 $\dot{\eta}$ 搬到 $L_{\dot{x}}$ 上：
$$\int_{t_1}^{t_2} L_{\dot{x}} \, \dot{\eta} \, dt = \underbrace{\Big[ L_{\dot{x}} \eta \Big]_{t_1}^{t_2}}_{= 0 \ (\eta(t_1) = \eta(t_2) = 0)} - \int_{t_1}^{t_2} \frac{d}{dt}\big( L_{\dot{x}} \big) \, \eta \, dt ,$$
于是
$$\delta S = \int_{t_1}^{t_2} \left( L_x - \frac{d}{dt} L_{\dot{x}} \right) \eta \, dt .$$

> [!note] 变分法基本引理
> 若连续函数 $g(t)$ 满足 $\int_{t_1}^{t_2} g(t) \, \eta(t) \, dt = 0$ 对**任意** $\eta$ 成立，则 $g \equiv 0$。
> 证明思路：取 $\eta$ 只在某点附近的一个小区间内非零（尖峰函数），即可逼出 $g$ 在该点为 $0$，再由连续性推广。

由此 $\delta S = 0 \ \forall \eta \iff L_x - \frac{d}{dt} L_{\dot{x}} = 0$，即欧拉-拉格朗日方程（équation d'Euler-Lagrange）。

> [!tip] 想法：分部积分的唯一目的
> 就是**把所有 $\delta$ 的导数搬走、让 $\eta$ 光溜溜地露出来**，这样才能用基本引理。掌握这一点，无论 $L$ 含 $\dot{x}$ 还是 $\ddot{x}$，套路只有一条：一路分部积分直到 $\eta$ 上没有任何导数。$L$ 含 $\ddot{x}$ 时要做两次，见 [[含二阶导数的拉格朗日量与欧拉-拉格朗日方程]]。

## 8. 最小作用量原理

> [!note] 最小作用量原理（principe de moindre action）
> 定义作用量 $S[x] = \int_{t_1}^{t_2} L(x, \dot{x}, t) \, dt$。真实运动 $x(\cdot)$ 是使 $S$ 取极值的曲线，即 $\delta S = 0$ 对一切满足边界条件 $\delta x(t_1) = \delta x(t_2) = 0$ 的扰动成立。等价于欧拉-拉格朗日方程。

"最小"一词是历史沿革，严格地说只是**驻定**（一阶变分为零）；极值性需二阶变分定号才成立。
