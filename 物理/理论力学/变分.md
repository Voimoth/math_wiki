# 变分（variation, dérivée variationnelle）

> [!question] 问题
> 变分和普通导数有什么区别？为什么它能给出一个微分方程而不只是一个方程？

## 定义：函数空间上的方向导数

平常的导数作用于数：
$$f: \mathbb{R} \to \mathbb{R}, \qquad f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
增量 $h$ 是**数**。

泛函的输入本身是函数、输出是数，例如作用量
$$S[x] = \int_{t_1}^{t_2} L\big(x(t), \dot{x}(t)\big) \, dt .$$
此时"$x$ 加一个增量"应当是**加一整个函数**。取固定的扰动方向 $\eta$，令
$$x_\varepsilon(t) = x(t) + \varepsilon \, \eta(t),$$
其中 $\varepsilon$ 是普通实数（走多远），$\eta$ 是一条固定的函数（往哪个方向走）。于是泛函退化为关于 $\varepsilon$ 的普通一元函数，变分即在其上求普通导数并取 $\varepsilon = 0$：

$$\delta S := \left. \frac{d}{d\varepsilon} S(\varepsilon) \right|_{\varepsilon = 0} .$$

> [!note] 变分是泛函的方向导数
> 函数空间无穷维，无法谈"梯度向量"，只能对每个方向 $\eta$ 谈方向导数。常用的等价写法
> $$\delta S = \int \frac{\delta S}{\delta x(t)} \, \eta(t) \, dt ,$$
> 其中 $\frac{\delta S}{\delta x(t)}$ 称为**变分导数**（dérivée variationnelle），即泛函的梯度的分量。

## 为什么一个数能挤出一整个方程

普通极值只有一个方程 $f'(x) = 0$；变分条件 $\delta S = 0$ 是

$$\delta S = 0 \quad \text{对所有方向 } \eta \iff \frac{\delta S}{\delta x(t)} = 0 \quad \text{对所有 } t .$$

左侧是"一个数等于零"，右侧是"逐点的函数等于零"——后者才是一整个微分方程。

## 与普通极值的对照

| | 一元微积分 | 变分法 |
|---|---|---|
| 变量 | $x \in \mathbb{R}$ | $x(\cdot)$ 属于函数空间 |
| 增量 | $h$ | $\eta(t)$ |
| 一阶条件 | $f'(x) = 0$ | $\delta S = 0$ 对所有 $\eta$ |
| 条件形态 | 一个方程 | 一个微分方程（逐点） |
| 二阶条件 | $f'' > 0$ | 二阶变分 $\delta^2 S$ 定号 |

## $\delta$ 的运算规则

| 规则 | 内容 | 理由 |
|---|---|---|
| 线性 | $\delta(L_1 + L_2) = \delta L_1 + \delta L_2$ | 导数线性 |
| 链式 | $\delta L = L_x \delta x + L_{\dot{x}} \delta \dot{x} + \cdots$ | 全微分/链式法则 |
| 与时间导数交换 | $\delta\!\left( \frac{dx}{dt} \right) = \frac{d}{dt}(\delta x)$ | 混合偏导相等 |

第三条的验证：由 $x_\varepsilon = x(t) + \varepsilon\eta(t)$ 中 $\varepsilon$ 与 $t$ 独立，
$$\delta \dot{x} = \frac{d}{d\varepsilon}\Big(\frac{dx}{dt} + \varepsilon\frac{d\eta}{dt}\Big)\Big|_{\varepsilon=0} = \frac{d\eta}{dt} = \frac{d}{dt}(\delta x) .$$

> [!warning] 陷阱：$\delta$ 与 $\frac{d}{dt}$ 交换不是公理
> 这条规则只对"被扰动的那条曲线本身"成立。若 $\delta$ 作用在像 $\frac{df(q,t)}{dt}$ 这种"绕过中间函数"的对象上，必须先展开验证，不能直接套用。
